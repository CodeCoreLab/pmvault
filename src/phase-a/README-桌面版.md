# 密码管理器（桌面版）

Windows 本地单机运行的密码管理器。解压即用，无需安装、无需部署服务器、无需联网、无需 PHP 或任何运行时。

## 快速开始

1. 把压缩包解压到任意目录（建议不要放在 `C:\Program Files`，避免写权限问题）
2. **双击 `vaultd.exe`**
3. 浏览器自动打开界面，首次使用按提示创建主账户

关闭程序：点击界面右上角「退出程序」即可（服务会一并停止）。

> 没有启动脚本，也不会弹出命令行黑窗口 —— 双击 exe 直接出界面。

## 两种密码，务必分清

| | 登录密码 | 主密钥密码 |
|---|---|---|
| 用途 | 登录系统 | 加密 / 解密所有密码数据 |
| 丢失后果 | 无法登录 | **无法解密数据，任何人都救不回来** |

建议二者不同。主密钥密码丢失 = 数据永久丢失，这是端到端加密的固有代价，不是缺陷。

## 数据存放位置

全部数据都在解压目录下的 `data\` 里：

```
data\passwords.db      主数据库（密码以 AES-256-GCM 加密存储）
data\backups\         自动 / 手动备份（保留最近 30 份）
```

- **备份方式**：整个文件夹复制走即可
- **迁移**：把 `data\` 复制到新机器的同一位置
- 每次登录会自动备份一次；也可以在界面里点「备份」手动创建
- 备份文件是**不加密的完整数据库副本**，请勿放进网盘或随手分享

## 安全设计

- **加密**：AES-256-GCM 认证加密（防篡改），密文格式 `版本号(1) ‖ IV(12) ‖ Tag(16) ‖ 密文`
- **密钥派生**：Argon2id（内存 64 MB / 迭代 2 / 并行 1），抗 GPU 与 ASIC 暴力破解
- **主密钥不落盘**：库里只存派生参数（salt + KDF 参数），每次解锁时重新派生
- **主密钥不进浏览器**：解密由本地服务进程完成，网页只拿到单条明文结果。
  即使页面存在 XSS，也拿不到主密钥
- **仅监听 127.0.0.1**：不对外开放端口，局域网其他设备无法访问
- **闲置 15 分钟自动上锁**：需要重新输入主密钥密码才能查看密码
- **双密码分离**：登录密码泄露不等于数据泄露

## 命令行参数（一般不需要）

```
vaultd.exe -addr 127.0.0.1:0   监听地址，默认随机端口
vaultd.exe -data D:\mydata     指定数据目录
vaultd.exe -open=false         不自动打开浏览器
```

## 与 PHP 版的关系

本程序的数据格式与 PHP 版**完全兼容**：同一个 `passwords.db` 两边都能打开读写，密文可互相解密（已实测双向验证）。

- 想从 PHP 版迁移过来：把旧版的 `data\passwords.db` 复制到本程序的 `data\` 目录即可
- 注意：旧版用户若当年是在 Windows + PHP 环境下创建、且 `kdf_type` 为 `pbkdf2`，本程序同样能正确派生密钥解密

## 常见问题

**Q：浏览器没自动打开？**
手动访问命令行窗口里显示的地址（形如 `http://127.0.0.1:52341/`）。

**Q：提示端口被占用？**
程序默认用随机端口，一般不会冲突。若出现，用 `vaultd.exe -addr 127.0.0.1:18080` 指定一个空闲端口。

**Q：换电脑怎么办？**
把整个文件夹（含 `data\`）拷过去即可，解压即用。

**Q：忘记主密钥密码？**
无法找回。请立刻从 `data\backups\` 找一份旧备份，用当时的主密钥密码尝试。这也是为什么建议定期把备份复制到安全位置。

**Q：能多人共用吗？**
不能。本程序是单账户本地保险箱，设计上就不支持多用户。

## 系统要求

- Windows 10 / 11，64 位
- 无需 .NET、无需 VC++ 运行库、无需任何其他依赖（Go 静态编译，单文件）
- 浏览器：Chrome / Edge / Firefox / 360 极速浏览器等任意现代浏览器

## 卸载

删除整个文件夹即可。程序不写注册表、不装服务、不在系统目录留任何文件。
（若曾用 `-data` 指向过其他目录，需一并删除那里）
